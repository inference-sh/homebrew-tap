# homebrew-tap

Homebrew tap for [inference.sh](https://inference.sh) CLI tools.

## install

```bash
brew install inference-sh/tap/belt
```

> **Homebrew 6.0+** requires trusting third-party taps before install.
> If you see `Refusing to load formula from untrusted tap`, run:
>
> ```bash
> brew trust inference-sh/tap
> ```
